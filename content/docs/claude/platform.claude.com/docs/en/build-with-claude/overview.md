## Platform features

Features of the Claude Platform that work across its APIs. Each feature’s page says where you can use it.

<Tip>
  You can discover which capabilities a model supports programmatically. The [Models API](https://platform.claude.com/docs/en/api/models/list?sdk_languages=cli) returns `max_input_tokens`, `max_tokens`, and a `capabilities` object for every available model.
</Tip>

| [Effort](https://platform.claude.com/docs/en/build-with-claude/effort?sdk_languages=cli)                                                                                  | A setting that controls how many tokens Claude spends on a response, trading thoroughness for token efficiency.                                                      |
| ↳ [Per-message effort](https://platform.claude.com/docs/en/build-with-claude/effort?sdk_languages=cli#change-effort-mid-conversation-beta)                                | Changing the effort level for later turns of a conversation with a per-message `output_config`, which keeps the prompt cache.                                        |
| [Fast mode](https://platform.claude.com/docs/en/build-with-claude/fast-mode?sdk_languages=cli)                                                                            | Up to 2.5 times more output tokens per second from supported models, at premium pricing.                                                                             |
| [Files API](https://platform.claude.com/docs/en/build-with-claude/files?sdk_languages=cli)                                                                                | Upload a file once and refer to it by `file_id` in later requests, and download files that skills or the code execution tool create.                                 |

| [Mid-conversation system messages](https://platform.claude.com/docs/en/build-with-claude/mid-conversation-system-messages?sdk_languages=cli)                              | A system instruction added partway through a conversation, without changing the top-level system prompt or the cached prefix before it.                              |
| ↳ [Mid-conversation tool changes](https://platform.claude.com/docs/en/build-with-claude/mid-conversation-system-messages?sdk_languages=cli#mid-conversation-tool-changes) | Offer or withdraw tools partway through a conversation without changing the tools array, so the cached prefix stays valid.                                           |
| ↳ [Turn-scoped system messages](https://platform.claude.com/docs/en/build-with-claude/mid-conversation-system-messages?sdk_languages=cli#turn-scoped-system-messages)     | A mid-conversation system message that applies only until the next user message, then stays in the history but renders nothing and costs no input tokens.            |
| [Multilingual support](https://platform.claude.com/docs/en/build-with-claude/multilingual-support?sdk_languages=cli)                                                      | Claude works in many languages, with strong performance relative to English.                                                                                         |
| [OpenTelemetry](https://platform.claude.com/docs/en/manage-claude/opentelemetry?sdk_languages=cli)                                                                        | Traces your Messages API requests, tool uses, and Managed Agents sessions with OpenTelemetry spans from the Claude SDK and the Claude API.                           |
| ↳ [API tracing](https://platform.claude.com/docs/en/manage-claude/opentelemetry/api?sdk_languages=cli)                                                                    | OpenTelemetry spans that the Claude API sends to your observability platform for each model request and tool use that it runs.                                       |
| ↳ [SDK tracing](https://platform.claude.com/docs/en/manage-claude/opentelemetry/sdk?sdk_languages=cli)                                                                    | OpenTelemetry spans that the Claude SDK emits in your application for each request it sends and each tool that its tool runner runs.                                 |
| [Parallel tool use](https://platform.claude.com/docs/en/agents-and-tools/tool-use/parallel-tool-use?sdk_languages=cli)                                                    | Claude can call several tools in one response.                                                                                                                       |
| [PDF support](https://platform.claude.com/docs/en/build-with-claude/pdf-support?sdk_languages=cli)                                                                        | Send PDFs to Claude so it can read the text, pictures, charts and tables in them.                                                                                    |
| [Programmatic tool calling](https://platform.claude.com/docs/en/agents-and-tools/tool-use/programmatic-tool-calling?sdk_languages=cli)                                    | Lets Claude call your tools from code in the code execution container, instead of one model round trip for each call.                                                |
| [Prompt caching](https://platform.claude.com/docs/en/build-with-claude/prompt-caching?sdk_languages=cli)                                                                  | Reuses a cached prompt prefix from a recent request to reduce processing time and cost.                                                                              |
| ↳ [1-hour duration](https://platform.claude.com/docs/en/build-with-claude/prompt-caching?sdk_languages=cli#1-hour-cache-duration)                                         | A 1-hour prompt cache lifetime, for a higher cache write price than the 5-minute default.                                                                            |
| ↳ [5-minute duration (default)](https://platform.claude.com/docs/en/build-with-claude/prompt-caching?sdk_languages=cli#how-prompt-caching-works)                          | The default prompt cache lifetime. Each use of the cached content refreshes it at no extra cost.                                                                     |
| ↳ [Automatic caching](https://platform.claude.com/docs/en/build-with-claude/prompt-caching?sdk_languages=cli#automatic-caching)                                           | Prompt caching with one top-level `cache_control` field: the cache breakpoint goes on the last cacheable block and moves forward as the conversation grows.          |
| ↳ [Cache diagnostics](https://platform.claude.com/docs/en/build-with-claude/cache-diagnostics?sdk_languages=cli)                                                          | Compares a request with your previous one and reports where the prompt prefix changed, to explain cache misses.                                                      |
| ↳ [Explicit cache breakpoints](https://platform.claude.com/docs/en/build-with-claude/prompt-caching?sdk_languages=cli#explicit-cache-breakpoints)                         | Prompt caching with `cache_control` on individual content blocks, to choose exactly what is cached.                                                                  |
| [SDK middleware](https://platform.claude.com/docs/en/cli-sdks-libraries/middleware?sdk_languages=cli)                                                                     | A hook in the Claude SDKs that runs your code before each request is sent and after its response is received.                                                        |
| [Search results](https://platform.claude.com/docs/en/build-with-claude/search-results?sdk_languages=cli)                                                                  | Content blocks that hold your own search results, with a source and title, so Claude can cite them the same way it cites web search results.                         |
| [Service tiers](https://platform.claude.com/docs/en/api/service-tiers?sdk_languages=cli)                                                                                  | Lets a request use your organization’s Priority Tier capacity.                                                                                                       |
| [Session budgets](https://platform.claude.com/docs/en/managed-agents/budgets?sdk_languages=cli)                                                                           | A hard spending limit in US dollars on one session, measured at public list prices.                                                                                  |

| [Structured outputs](https://platform.claude.com/docs/en/build-with-claude/structured-outputs?sdk_languages=cli)                                                          | Constrains Claude’s response to a JSON schema that you give, so the output is valid and parseable.                                                                   |

| ↳ [Adaptive thinking](https://platform.claude.com/docs/en/build-with-claude/thinking-steering-and-cost?sdk_languages=cli)                                                 | Thinking mode in which Claude decides, for each request, whether to think and how much.                                                                              |
| ↳ [Extended thinking](https://platform.claude.com/docs/en/build-with-claude/extended-thinking?sdk_languages=cli)                                                          | Manual thinking mode in which you set a fixed thinking token budget (`budget_tokens`) on each request.                                                               |
| ↳ [Preserved thinking](https://platform.claude.com/docs/en/build-with-claude/preserved-thinking?sdk_languages=cli)                                                        | Claude uses thinking blocks from earlier turns only if the current model can read them and nothing before them (system prompt, tools, earlier messages) has changed. |
| [Threshold compaction](https://platform.claude.com/docs/en/build-with-claude/compaction-threshold?sdk_languages=cli)                                                      | Automatic compaction: when a conversation reaches a token threshold, the API summarizes older context inside the request.                                            |
| [Token counting](https://platform.claude.com/docs/en/build-with-claude/token-counting?sdk_languages=cli)                                                                  | Counts the tokens in a message before you send it to Claude.                                                                                                         |

| [Tool search tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/tool-search-tool?sdk_languages=cli)                                                      | Lets Claude search your tool catalog and load only the tool definitions it needs.                                                                                    |

| [Web fetch tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-fetch-tool?sdk_languages=cli)                                                          | A server tool that lets Claude get the full content of web pages and PDF documents at given URLs.                                                                    |
| [Web search tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-search-tool?sdk_languages=cli)                                                        | A server tool that lets Claude search the web for current information.                                                                                               |

| [Text editor tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/text-editor-tool?sdk_languages=cli)                              | Lets Claude view, create, and edit text files with an Anthropic-defined tool.                                                                |

| [Vaults](https://platform.claude.com/docs/en/managed-agents/vaults?sdk_languages=cli)                                       | Stores of per-user credentials for third-party services that you register once and reference by ID when you create a session.                                |
| [Webhooks](https://platform.claude.com/docs/en/managed-agents/webhooks?sdk_languages=cli)                                   | Notifications to your HTTPS endpoint when events happen in your Managed Agents resources, such as a change in a session’s status.                            |
