An Admin API key authenticates calls to the APIs that manage and report on your organization, such as the [Admin API](https://platform.claude.com/docs/en/manage-claude/admin-api?sdk_languages=cli) and the [Compliance API](https://platform.claude.com/docs/en/manage-claude/compliance-api?sdk_languages=cli). One key can work with several of these APIs.

## Which key do you need?

The key you need depends on which Claude product your organization uses: Claude Console (Claude Platform) or Claude Enterprise.

Most keys reach only the organization you created them in. Some keys, such as those with Compliance API, group, or audit scopes, can reach further if your company links its organizations under a [parent organization](https://platform.claude.com/docs/en/manage-claude/compliance-api-access?sdk_languages=cli#which-key-do-you-need). If your company uses both Claude Console and Claude Enterprise, create one key in each.

## Create a key for a Claude Console organization

An individual Claude Console account cannot create this key, so [set up an organization](https://platform.claude.com/docs/en/manage-claude/admin-api?sdk_languages=cli#availability) first. To use the key with the Activity Feed, [enable the Compliance API](https://platform.claude.com/docs/en/manage-claude/compliance-api-access?sdk_languages=cli#set-up-the-compliance-api) before you create it.

<Steps>
  <Step title="Open Admin keys settings">
    Sign in to the Claude Console as an [organization admin](https://platform.claude.com/docs/en/manage-claude/admin-api?sdk_languages=cli#organization-roles-and-permissions). Go to the [Admin keys](https://platform.claude.com/settings/admin-keys) page (`platform.claude.com/settings/admin-keys`).
  </Step>

  <Step title="Create the key">
    Click **Create admin key**, give it a name, select a [key expiration](https://platform.claude.com/docs/en/manage-claude/authentication?sdk_languages=cli#key-expiration), and click **Add**.
  </Step>

  <Step title="Copy and store the secret">
    Copy the displayed secret (starting with `sk-ant-admin01-`) and store it in your secrets manager. The full secret is shown only once.
  </Step>
</Steps>

## Create a key for a Claude Enterprise organization

<Steps>
  <Step title="Open API settings">
    Sign in to claude.ai as the [primary owner or an organization owner](https://platform.claude.com/docs/en/manage-claude/user-management?sdk_languages=cli#organization-roles). Go to [claude.ai > Organization settings > API](https://claude.ai/admin-settings/api-access) and find the **Keys** section.
  </Step>

  <Step title="Create the key">
    Click **Create key**, name the key, and select the scopes you need from the [scopes table](https://platform.claude.com/docs/en/manage-claude/admin-api-keys?sdk_languages=cli#choose-scopes-for-a-claude-enterprise-key). The primary owner can combine scopes from different APIs (for example, `read:analytics` and `read:spend_limits`) on a single key.

    If the **Key access** options appear when you select a Compliance API scope, **Only this organization** is selected by default. To reach every organization under your parent organization, choose **All organizations**. Such a key can hold only Compliance API, group, and audit scopes.

    Click **Create**. If the key has the `delete:compliance_user_data` scope, also click **Confirm and create key**.
  </Step>

  <Step title="Copy and store the secret">
    Copy the displayed secret (starting with `sk-ant-api01-`) and store it in your secrets manager. The full secret is shown only once.
  </Step>
</Steps>

## Choose scopes for a Claude Enterprise key

When you create a Claude Enterprise key, select every scope that the APIs you plan to call require. Scopes are fixed at creation; to add a scope later, create a new key. A key that holds only Compliance API scopes is also called a Compliance Access Key. A key that holds only `read:analytics` is also called an Analytics API key.

The `read:plugins` and `write:plugins` scopes need an organization that can use the [Plugins API](https://platform.claude.com/docs/en/manage-claude/plugins-api?sdk_languages=cli), and they act only on the organization you created the key in. Keys with `read:org_audit` or `read:compliance_org_data` can read the Plugins API only in organizations that can use it. See [Plugins API scopes](https://platform.claude.com/docs/en/manage-claude/plugins-api?sdk_languages=cli#scopes). To read another organization’s plugins, see [Reading another organization under the same parent](https://platform.claude.com/docs/en/manage-claude/plugins-api?sdk_languages=cli#reading-another-organization-under-the-same-parent).

## Use the key

Pass the key in the `x-api-key` header on every request. See each API’s documentation for complete request examples.

A call to an endpoint outside the key’s scopes returns `403 Forbidden`. The error message names the scopes the endpoint accepts.

Neither a Claude Console key nor a Claude Enterprise key works with the Admin API’s service-account, federation-issuer, or federation-rule endpoints. Those endpoints accept only an OAuth bearer token with the `org:admin` scope. See [OAuth bearer token](https://platform.claude.com/docs/en/manage-claude/admin-api?sdk_languages=cli#oauth-bearer-token).
